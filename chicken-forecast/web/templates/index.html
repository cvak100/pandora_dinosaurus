Validacija modela

Model se uči na starejših tednih, nato preverimo zadnjih {{ metrics.val_weeks }} tednov (brez mešanja — časovni split). Manjši MAE/RMSE = boljša napoved. Če je LightGBM MAE manjši od Baseline MAE, model premaga golo sezono.

Val MAE {{ "%.2f"|format(metrics.val.mae) }}

Povprečna absolutna napaka (jajca/teden) na validaciji. Če MAE = 5.7, se model v povprečju zmoti za ~6 jajc na teden.

Val RMSE {{ "%.2f"|format(metrics.val.rmse) }}

Korenska srednja kvadratna napaka. Bolj kaznuje velike zgreške kot MAE. Če je RMSE bistveno večji od MAE, so občasni večji missi.

Val R² {{ "%.3f"|format(metrics.val.r2) }}

Delež pojasnjene variance (1 = popolno, 0 = kot povprečje, <0 = slabše od povprečja). ~0.5 pomeni, da model ujame približno polovico nihanj.

Baseline MAE {{ "%.2f"|format(metrics.val_seasonal_baseline.mae) }}

Napaka preproste sezonske napovedi (zgodovinska jajca/kokoš za ta teden × število kokoši). Primerjalni “floor” — LightGBM mora biti boljši od tega.

Train / Val tedni {{ metrics.train_weeks }} / {{ metrics.val_weeks }}

Število tednov za učenje / preverjanje. Val so vedno zadnji tedni v času (ne naključni), da ne “pokukamo” v prihodnost.

Val obdobje {{ metrics.val_start }} → {{ metrics.val_end }}

Datumski razpon validacijskih tednov (začetek ISO tedna). Na teh tednih merimo MAE/RMSE/R² zgoraj.
